# Code of Conduct

This project is a working environment for contributors of varied backgrounds,
experience levels and institutional contexts. These expectations apply in every project
space: issues, pull requests, discussions and any channel the project runs.

## Expectations

- Engage with respect and good faith. Disagree on substance; don't attack people.
- Assume good faith until evidence shows otherwise.
- Welcome newcomers. The subject is dense, and first questions are valid questions.
- Critique the work, not the person who did it.
- Own your mistakes, and help others learn from theirs.
- Keep to the project's scope. Off-topic content belongs elsewhere.

## Unacceptable Behavior

Behavior that targets, threatens, demeans or harasses another participant is grounds for
removal. A reporter doesn't have to describe the form it took for a report to be valid.

## Reporting

Report a concern through GitHub private vulnerability reporting, the same private channel
used for security reports (see [SECURITY.md](SECURITY.md)). Maintainers read reports in
confidence. Reporters are told what action was taken; the person reported is told what
was reported and given a chance to respond.

## Enforcement

Maintainers may ask for changes, edit or remove content, restrict participation in a
space, or remove a participant. Action is proportionate to the behavior and to whether
earlier guidance was ignored.

## Scope

This covers conduct in project spaces, and conduct elsewhere when it materially affects
participants' ability to take part in the project.

## Changes

Material changes to this document are recorded in [CHANGELOG.md](CHANGELOG.md) and go
through the normal pull request process.
